# README

## 1. Nombre y frase

**Nonograma 5x5: Descubre el Pixel Art**

Un juego de lógica rápida donde pintás casillas de una cuadrícula siguiendo números para descubrir un dibujo oculto.

## 2. Qué hace y cómo se usa

Iniciá una partida y seguí las pistas de filas y columnas del tablero 5 × 5.  
Elegí Pintar o Marcar X y tocá una celda; con flechas movés el cursor y con espacio aplicás el modo elegido.  
Usá «Comprobar dibujo» o Enter/C para validar; la partida termina al resolver el tablero o al superar tres errores.

## 3. Enlace

[Abrir el juego](http://localhost:5173/)

## 4. Cómo correrlo en otra máquina

Con Node.js y npm instalados, desde la carpeta del proyecto ejecutá:

```sh
npm install
npm run dev
```

Después abrí [http://localhost:5173/](http://localhost:5173/) en el navegador.
